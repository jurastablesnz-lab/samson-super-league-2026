# Samson's Dressage Training Plan 2026

Level 2 Super 5 season planner for Jura Samson.

## Run
Node.js 22+.
```
npm install
npm run dev
```
Opens on http://localhost:8080

Judge-sheet summaries need `XAI_API_KEY` in the environment.
The freestyle MP3 is not in this repo. Put it at `public/audio/samson-l2-mfs.mp3` if you have it.
Competition videos and sheet photos stay in the browser that took them.
